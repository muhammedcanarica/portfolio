# Can Arıca Portfolio

Can Arıca'nın seçilmiş yazılım ve oyun projelerini sunan, Türkçe ve İngilizce kişisel portfolyosu.

[Canlı site](https://muhammedcanarica.github.io/portfolio/) · [GitHub profili](https://github.com/muhammedcanarica)

## İçerik

- NetScope, CamerBound, DungeonWeaver, PipeMuzzle, AirTune ve Wimmia için proje sunumları
- Hakkımda, teknolojiler ve iletişim bölümleri
- Türkçe ve İngilizce dil desteği
- İndirilebilir CV
- Etkileşimli chibi portfolyo asistanı
- Masaüstü ve mobil ekranlara uyumlu arayüz

Arayüz; güçlü tipografi, geniş boşluklar ve ince ayraçlarla hazırlanmış sade bir editoryal yapıya sahiptir. Proje verileri arayüz bileşenlerinden ayrı tutulur.

## Teknolojiler

React 18 · Vite 5 · JavaScript · CSS

## Yerel çalıştırma

```bash
npm install
npm run dev
```

Üretim derlemesi:

```bash
npm run build
npm run preview
```

Yazılı içerikler `src/data/content.js`, proje bilgileri `src/data/projects.js`, iletişim bağlantıları `src/data/contactLinks.js` dosyalarında bulunur. Her içerik değişikliğinde Türkçe ve İngilizce alanları birlikte güncellenmelidir.

## English

A bilingual personal portfolio presenting selected software and game projects by Can Arıca.

[Live site](https://muhammedcanarica.github.io/portfolio/) · [GitHub profile](https://github.com/muhammedcanarica)

### Content

- Project presentations for NetScope, CamerBound, DungeonWeaver, PipeMuzzle, AirTune and Wimmia
- About, technologies and contact sections
- Turkish and English language support
- Downloadable CV
- Interactive chibi portfolio assistant
- Responsive desktop and mobile layout

The interface uses strong typography, generous spacing and thin separators in a restrained editorial layout. Project data is kept separate from presentation components.

### Local setup

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
npm run preview
```

Written content lives in `src/data/content.js`, project information in `src/data/projects.js`, and contact links in `src/data/contactLinks.js`. Update both Turkish and English fields when changing content.
